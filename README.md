# Excel Data Analytics Project

## Project Overview

This project demonstrates my data analytics skills using Microsoft Excel. It focuses on data cleaning, data analysis, data visualization, and interactive dashboard development.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Visualization

## Project Objectives

- Analyze the available dataset.
- Identify important trends and patterns.
- Create meaningful insights from the data.
- Develop an interactive Excel dashboard.
- Support data-driven decision-making.

## Dashboard Preview

The project includes an interactive Excel dashboard for exploring and understanding the analyzed data.

## Project Files

- **Students Dashboard.xlsx** – The complete Excel workbook containing the interactive Student Dashboard and supporting data sheets. The data and supporting sheets are hidden to maintain a clean dashboard presentation while preserving the workbook's functionality.

## Key Features
- Interactive Student Dashboard
- Data visualization
- Excel-based analysis
- Dashboard navigation and filtering (where implemented)
